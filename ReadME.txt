setup Instructions:

1.cloning the repo:
  a.open git bash
  b.Run command "git clone https://github.com/NehaBaranwal88/ReqResAPIAutomation.git"
  c.cd ReqResAPIAutomation
or
1.Unzip the attached Project
    
2.Import the Project
  a.Open IDE(i.e Eclipse).
  b.Import the project as a Maven project.
   
3.Configure Dependencies
   Ensure the following dependencies are present in pom.xml:
   1.Rest-assured
   2.TestNG
   3.log4j
   4.extent report
   5.jackson-databind
   6.java faker
   7.Maven surefire plugins
   8.Maven compiler plugins 
   
 4. Run the testcases.
   1.Using the Maven
     Prequiste:Java jdk and Apache Maven should be installed
     a.Run command "mvn clean install"
       
   2.Using testng.xml suite
    a.Right click on testng.xml file and select option Run as TestNG suite. 
    
 5.See the generated Report
  a.Go to Reports folder and Refresh.
  b.Right click latest Report and Open with System Editor.
  
 6.See the Automation logs
  a.Go to logs folder and Refresh.
  b.check the automation.log file
